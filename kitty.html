云端同步 · 多平台记录本地永远是主副本，云端只当中转
推荐（GitHub Gist）：① 去 github.com/settings/tokens → Generate new token (classic) → 勾选 gist → 生成后把令牌粘进 Token 框；② 点「创建云端存档」得到同步码；③ 其他设备只填同步码就能拉取（不需要 Token）。存档是私密 Gist，只有凭码能看。
Token 只保存在你自己设备的浏览器里，不会写进云端。公共中转站只是小数据兜底（容量不到 20KB，存档可能被清理）；无论如何，本机数据 + 导出的 JSON 备份才是根本。

这个文件是怎么运作的
· 整个工作台就这一个 HTML 文件，双击用浏览器打开就能用，不需要联网、不需要装 Python。
· 数据写在浏览器的 localStorage 里（键名 kitty_v1），不上传任何服务器。
· 因此：换浏览器、换电脑、清理浏览器缓存都会丢数据 —— 这是本地文件的代价，所以用「导出 JSON」来兜底。
· 想换台设备继续看：在这台导出 JSON，在那台打开同一个 HTML 文件后「从 JSON 恢复」即可。
· 想彻底放心：把这个 HTML 和备份 JSON 一起放进网盘同步文件夹，就相当于云端同步了。
